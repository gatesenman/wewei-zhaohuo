# 中国产业带城市 × 货源网站研究（维维找货 v3.4）

调研方法：WebSearch（1688 产业带频道、官方市场名录、行业网站）+ 盒子 curl 实测搜索 URL（测试机位于境外，部分站点 403/超时）+ 应用内 E2E 抓取。只把搜索 URL 可用且有真实 logo 的网站加入应用；其余以“1688/百度爱采购 + 城市名”方式覆盖。

## 1688 产业带说明
- 1688 产业带频道（page.1688.com/industrybelt）按市场/楼层/档口索引商家，但没有公开稳定的“按城市筛选”URL 参数；s.1688.com 的 keywords 需 GBK 编码，地区筛选在页面内完成。
- 因此应用内“产业带找货”采用：**勾选当地专业站 + 综合B2B（1688、百度爱采购、世界工厂网、中国制造网、慧聪网），并在综合B2B的关键词前自动加城市名**（如“义乌 保温杯”），实测这是 1688/爱采购上定位产地最稳的方式。

## 使用建议
1. 找源头工厂：选产业带城市 → 1688（登录后）+ 百度爱采购结果最全。
2. 服装鞋包档口货：杭州四季青（货捕头、17网）、广州（搜款网/网商园）、晋江（鞋库网）、成都（购途网）、织里（3E女装）。
3. 电子：深圳华强北 → 立创商城、华秋、云汉芯城、华强电子网。
4. 国内网络 + 登录后效果显著好于境外测试结果。
