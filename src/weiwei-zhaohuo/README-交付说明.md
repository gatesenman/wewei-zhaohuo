## 怎么用

1. 双击安装程序或绿色版，打开「维维找货」。
2. 左侧勾选要搜的平台（可切换「全部 / 零售 / 批发货源」）。
3. 输入关键词，点「一键找货」；也可以拖入图片做以图搜货。
4. 需要登录的平台：点进度条上的「去登录」，登录后会话会保持。
5. 卡片可收藏、对比、导出 CSV/Excel；「用这张图找同款」可一键反向搜图。

## 版本演进

- **v2.2**：内嵌浏览器多窗格，移动端/电脑端、错误提示、AI 入口修复。

## 网络说明

测试机在中国大陆以外，淘宝/京东/拼多多等常要求登录或风控；国内网络登录后识别率会明显更高。义乌购、苏宁、网易严选、1688、中国制造网在测试中可直接出结果。
