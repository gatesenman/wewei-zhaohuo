# 维维找货 v3.2 · UI 走查 & 端到端测试报告

测试环境：Linux xvfb 1440×900，`WW_E2E=e2e-v32 WW_E2E_PHASE=v3 WW_V31=1`；测试机位于中国大陆境外，且未登录任何账号，部分平台被风控/登录墙拦截。截图见 `e2e-v32/`。

## 本版改动
- 平台由 30 个扩充到 **58 个**，新增 28 个，每个都用离线的真实 logo（128px PNG），没有文字图标。
- 分类从“零售/批发”两类改为 7 类：综合 8、内容直播 6、垂直品类 13、本地生活 11、二手 5、跨境 2、批发货源 13。侧栏有 8 个分类筛选按钮（4×2 排列），“全部”视图下每个平台旁带彩色分类角标。
- 平台设置中显示“需登录”标签；侧栏悬停提示会注明“搜索需登录”。
- 状态栏的分母不再计入“只能手动打开”的平台，另外单独显示“N 个需手动打开”。
- 老用户升级时，内置平台会自动迁移到新分类；新增的平台追加在列表末尾。

## UI 走查（浅色 / 深色）
| # | 问题 | 处理 |
|---|---|---|
| 1 | 分类从 3 个变成 8 个，原来的 3 列分段控件放不下 | 改为 4×2 网格，文字不换行 |
| 2 | “内容直播”角标太长，把平台名挤成省略号 | 角标统一为两个字（内容/垂直/本地/跨境…） |
| 3 | 新加的“需登录”锁形图标和登录状态图标重复，容易混淆 | 侧栏去掉该图标，改为悬停提示；设置页显示“需登录”标签 |
| 4 | 状态栏“8/58 有结果”把只能手动打开的平台也算进去，显得失败很多 | 分母去掉手动平台，另外显示“N 个需手动打开” |
| 5 | 深色模式下分类角标对比度不够 | 为每个分类单独设置深色配色 |
| 6 | 本机负载高，全部 58 个平台并发时，第二轮“全部完成”耗时 391 秒 | 已知问题；建议只勾选常用平台，或使用 45 秒超时设置（首批结果 0.1 秒内即可出现） |
