# 维维找货 v3.1 · UI 走查报告

修复前截图：`e2e-v30/`（v3.0 终版）。修复后截图：`e2e-v31/`。v3.1 的目标是更快找到货。

## 新增功能（找货效率）
- **找同款**：卡片右上角新增相机按钮，用这件商品的主图一键以图搜同款。会自动勾选支持以图搜货的平台。
  - 截图：e2e-v31/ui-24-find-same.png（1688 返回 7 件）。
- **全网最低价入口**：结果栏显示“最低 ¥x · 平台”，点击直接打开这件商品。
  - 截图：e2e-v31/ui-22-best-deal.png、ui-24-find-same.png。
- **状态栏时间**：同时显示“首批结果 x 秒”和“全部完成 y 秒”，用户可以先看已经出来的结果。
- **单个平台最长等待**（设置 → 常规）：可选 20 / 30 / 45 / 60 / 90 秒，默认 45 秒。超时的平台自动跳过，不拖慢整体。
  - 截图：e2e-v31/ui-25-settings-timeout.png。
- **启动预热**：启动 4 秒后，后台空闲预加载已选平台的首页（最多 2 个并行），首次搜索更快。
- **以图搜货提速**：图片搜索单独给更长的时间预算，提取轮次减半。1688 以图搜货从 v3.0 的超时变为成功出结果。

## Logo 核验
- 平台 Logo 都是离线打包的官方图标：src/assets/platforms/<id>.png，共 30 个，128px。
- 走查截图中逐一确认了这些位置：侧边栏、卡片角标、进度胶囊、表格平台列、对比弹窗、平台管理。
- 自定义平台的 Logo：先自动抓取官网 favicon，也可以自己上传；抓取失败时才用彩色首字母兜底。
